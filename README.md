# 💰 Expense & Budget Visualizer

Expense & Budget Visualizer adalah aplikasi web sederhana untuk membantu pengguna mencatat, mengelola, dan memvisualisasikan pengeluaran sehari-hari.

Proyek ini dibuat sebagai bagian dari pembelajaran Software Engineering.

---

## 🚀 Fitur Utama

### 1. Input Transaksi

Pengguna dapat menambahkan transaksi dengan informasi:

- Nama item
- Nominal pengeluaran
- Kategori
- Tanggal transaksi

Kategori bawaan:

- Makanan
- Transportasi
- Hiburan

---

### 2. Transaction List

Menampilkan seluruh transaksi yang telah ditambahkan.

Informasi yang ditampilkan:

- Nama transaksi
- Nominal
- Kategori
- Tanggal

Pengguna juga dapat menghapus transaksi.

---

### 3. Total Pengeluaran

Aplikasi secara otomatis menghitung:

- Total pengeluaran
- Total transaksi
- Rata-rata transaksi
- Pengeluaran terbesar

---

### 4. Visual Chart

Aplikasi menggunakan Pie/Doughnut Chart untuk menampilkan distribusi pengeluaran berdasarkan kategori.

Grafik akan diperbarui secara otomatis ketika:

- Transaksi ditambahkan
- Transaksi dihapus

---

## ⭐ Fitur Opsional

Proyek ini juga memiliki 3 fitur opsional:

### Custom Categories

Pengguna dapat membuat kategori pengeluaran sendiri.

Contoh:

- Pendidikan
- Kesehatan
- Belanja
- Tagihan

---

### Monthly Summary

Pengguna dapat melihat:

- Total pengeluaran per bulan
- Jumlah transaksi per bulan
- Kategori pengeluaran terbesar

---

### Dark/Light Mode

Pengguna dapat mengubah tampilan aplikasi antara:

- Light Mode
- Dark Mode

Preferensi tema disimpan menggunakan Local Storage.

---

## 💾 Data Storage

Aplikasi menggunakan:

`Browser Local Storage API`

Semua data transaksi disimpan secara lokal di browser pengguna.

Tidak menggunakan backend server.

---

## 🛠️ Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Local Storage API
- GitHub Pages

Tidak menggunakan:

- React
- Vue
- Angular
- Backend Server
